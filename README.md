# FROZZY Frozen Foods — website

Single-page brand website built with React, Vite, TypeScript, Tailwind CSS, Framer Motion and Lucide icons.
All orders and enquiries go to WhatsApp (+91 70256 45506). There is no cart, checkout or backend.

## Upload to Hostinger (Premium shared hosting)

The ready-to-upload build is **`../frozzy-hostinger-upload.zip`** (about 2 MB).

1. hPanel → **Websites** → your domain → **File Manager** → open `public_html`.
2. Delete the default `default.php` / `index.html` placeholder if one is there.
3. Upload `frozzy-hostinger-upload.zip` into `public_html`, right-click it → **Extract** (extract into `public_html` itself, not a sub-folder), then delete the zip.
   `public_html` should now contain `index.html`, `.htaccess`, `assets/`, `favicon.svg` …
4. hPanel → **Security → SSL**: make sure SSL is active. The included `.htaccess` redirects every visit to HTTPS, enables compression and sets long browser caching for images, CSS and JS.
5. Open the domain. Hard-refresh (Ctrl+F5) if you still see the old page.

> Hidden files: `.htaccess` starts with a dot. If File Manager doesn't show it, enable "Show hidden files" in its settings; it is inside the zip.

**Updating later:** edit the code, run `npm run build`, then upload the contents of `dist/` the same way (replace the old `assets/` folder).

## Commands

```bash
npm install        # once
npm run dev        # local development at http://localhost:5173
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build locally
npm run images     # re-optimise photos from raw/ into src/assets (WebP)
```

## Where to change things

| To change… | Edit |
|---|---|
| WhatsApp number, Instagram, address | `src/config/site.ts` |
| WhatsApp message wording | `src/utils/whatsapp.ts` |
| Products, categories, pack sizes, prices | `src/data/products.ts` (add `price: "₹450"` to show a price) |
| Brand colours and fonts | `tailwind.config.js` |
| Navbar sections | `NAV_ITEMS` in `src/config/site.ts` |
| SEO title, description, social preview | `index.html` |

### Product photos

Product cards currently use free **Unsplash** stock photos ([licence](https://unsplash.com/license)) that represent each product type; the page says so under the grid. To use your own pack shot:

1. Save it as `raw/products/<product-id>.jpg` (e.g. `raw/products/habit-panko.jpg`; ids are in `src/data/products.ts`).
2. Run `npm run images`, then `npm run build`.

The Instagram gallery uses FROZZY's own posts (in `raw/ig/`). To add a newer post, save the image into `raw/ig/`, run `npm run images`, and import it in `src/components/Instagram.tsx`.

```
├── utils/whatsapp.ts  WhatsApp links and messages

├── App.tsx            the single page (all sections in order)
└── index.css          Tailwind layers + scalloped section edges
public/                favicon, Open Graph image, .htaccess (copied as-is into dist/)
raw/                   original source photos (not deployed)
```
